# 🎭 FaceBlur Studio v0.9

**FaceBlur Studio** (AutoFaceBlur) — кроссплатформенное десктопное приложение для автоматического и локального скрытия лиц на видео с использованием нейросетей. Инструмент сочетает в себе полную приватность, высокую скорость обработки и интерфейс в стиле профессионального видеоредактора.

---

## 🚀 Основные возможности

* **Автоматический трекинг:** Детекция и отслеживание объектов на базе модели **YOLOv8-face**.
* **Рендеринг на лету (On-the-fly):** Мгновенный просмотр кадра без задержек и предварительного просчета всего файла.
* **Гибкая настройка масок:**
  * **Сила размытия (Blur Intensity):** От мягкого расфокуса до полной пикселизации.
  * **Размер маски (Padding):** Настройка области перекрытия вокруг лица.
  * **Мягкость краев (Fade):** Плавный градиент перехода границ размытия.
  * **Форма маски:** Регулировка геометрии от квадрата до овала.
* **Интерактивный выбор:** Включение и отключение объектов через галерею или двойным кликом по кадру.
* **Сохранение проектов:** Экспорт и импорт метаданных разметки в формате `.fbp` (FaceBlur Project).
* **Сохранение аудио:** Полная сохранность оригинальной звуковой дорожки через FFmpeg.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone [https://github.com/sirdimitry/AutoFaceBlur.git](https://github.com/sirdimitry/AutoFaceBlur.git)
cd AutoFaceBlur
```

---

### 2. Настройка окружения

#### 🍏 macOS

```bash
# Создание и активация окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

#### 🪟 Windows (PowerShell)

```powershell
# Создание и активация окружения
python -m venv venv
.\venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt
```

---

### 3. Запуск приложения

```bash
python main.py
```
